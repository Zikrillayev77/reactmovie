- ▶️ Tugma orqali YouTube'dagi treylerni ochish
- 🧩 Ma'lumotlar alohida massivda saqlanadi va `map()` bilan chiqariladi

## 📁 Tuzilma

```
src/
├── Kino.jsx   # Filmlar ro'yxati va kartalar

├── App.jsx
└── main.jsx
```

## 🚀 Ishga tushirish

```bash
git clone https://github.com/Zikrillayev77/reactmovie.git
cd reactmovie
npm install
npm run dev
```

Brauzerda `http://localhost:5173` manzilini oching.

Production uchun build:

```bash
npm run build
npm run preview
```
